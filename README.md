# Manohar Kumar Sah — 3D Portfolio

A modern interactive portfolio website for Manohar Kumar Sah, built with React, TypeScript, Vite, Three.js, and GSAP. The site combines animated sections, a physics-based tech stack showcase, custom cursor interactions, and smooth scrolling to present AI/ML, research, and product work in a polished single-page experience.

## Features

- Animated landing, about, career, work, and contact sections
- Physics-based 3D tech stack visualization with React Three Fiber and Rapier
- GSAP-powered scroll transitions and split-text effects
- Custom cursor and hover interactions
- Responsive one-page layout optimized for desktop and mobile
- Loading screen with animated progress and marquee text
- Project carousel with external links

## Tech Stack

- React 18
- TypeScript
- Vite
- Three.js
- React Three Fiber
- React Three Rapier
- GSAP
- CSS

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Production Build

```bash
npm run build
npm run preview
```
